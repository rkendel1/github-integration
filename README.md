# github-integration

Platform-native standalone GitHub integration boundary for the AppPort/AuthBoundry/FeltDB stack.

## Development

```bash
npm install
npm test
npm start
```

## HTTP API

- `GET /health`
- `GET /v1/ui`
- `POST /v1/webhooks/github`
